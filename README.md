## About the Project

This repository contains three web development activities focused on
designing user-friendly websites using HTML and CSS. The activities
demonstrate website introductions, organized content, attractive
layouts, and responsive design concepts.

## Activities

### Activity 1: Online Food Ordering Website

**Case:** 8

This project presents an online food ordering website where customers
can explore restaurants, browse food categories, compare prices,
discover special offers, and choose dishes.

**Key concepts:** - Food categories and menu presentation - Food cards
and attractive backgrounds - Responsive layouts and mobile-friendly
navigation - User interface and user experience design

### Activity 2: Electronics Store Website

**Case:** 7

This project presents an online catalog for electronic products such as
laptops, smartphones, headphones, smartwatches, cameras, and computer
accessories.

**Key concepts:** - Organizing products into categories - Displaying
product features and prices - Comparing specifications and showing
discounts - Creating a clear, professional-looking catalog

### Activity 3: Online Shopping Website

**Case:** 6

This project introduces an e-commerce website where customers can browse
products such as electronics, clothing, footwear, home appliances,
books, and accessories.

**Key concepts:** - Product images and descriptions - Prices, discounts,
ratings, and availability - Easy navigation and responsive layouts -
Convenient online product browsing

## Technologies Used

-   **HTML:** Structures the webpage content.
-   **CSS:** Styles the pages, including layouts, colors, backgrounds,
    and product or food cards.
-   **Responsive Design:** Helps pages adapt to different screen sizes.

## Learning Outcomes

By completing these activities, students can: - Understand the basic
structure of a website. - Explain how HTML and CSS are used in web
development. - Organize information into clear sections and cards. -
Recognize the importance of responsive design and easy navigation. -
Apply basic UI/UX principles to website layouts.

## Conclusion

These activities provide practical exposure to common website designs:
food ordering, electronics catalogs, and online shopping. They help
build foundational web development skills and an understanding of how
clear presentation and user-friendly navigation improve the browsing
experience.
